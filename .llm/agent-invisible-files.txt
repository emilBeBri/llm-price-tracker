# Agent invisible files
#
# One path per line, relative to the project root.
# Blank lines and lines starting with # are ignored.
#
# Paths listed here are completely hidden from the LLM agent:
# - read_file cannot read them
# - write_file / replace_in_file / regex_replace_in_file cannot modify them
# - fd / ripgrep / list_directory do not reveal them
#
# Use this for secrets, private notes, large generated data, or anything the
# agent should behave as if it cannot see at all.
#
# Examples:
# secrets/
# private-notes.md
# data/raw-client-export.csv
#
# --- Per-model scoping (optional) ---
# A line of the form [pattern] starts a section that applies ONLY when the
# active model name matches the glob `pattern` (case-insensitive). Paths
# before any [..] header, or under [*], are GLOBAL (apply to every model).
# Matching uses fnmatch, so `claude-*-dev` matches all Anthropic-on-Azure
# `-dev` models. A model gets the union of the global section plus every
# matching scoped section. With no active model, only global/[*] apply
# (fail-open). This is a soft guardrail, NOT a security sandbox.
#
# Example:
# [claude-*-dev]
# internal/anthropic-eval-set.csv
#
# [gemini-*]
# private/gemini-only-secret.txt
